# Hotfix 1.0.6 — Acabamento do Perfil na Sidebar

## Objetivo
Refinar o rodapé da sidebar após validação visual no WordPress real, preservando o perfil funcional implementado na versão 1.0.5.

## Alterações
- aumenta o espaço útil disponível para o e-mail da conta;
- move a ação **Sair** para uma segunda linha alinhada ao bloco do perfil;
- substitui o desenho anterior do ícone de saída por uma representação mais limpa;
- adiciona uma separação visual discreta antes de **Recolher**;
- mantém avatar, nome, e-mail, logout seguro, recolhimento da sidebar e preferência local;
- mantém rolagem interna e todos os grupos de navegação.

## Preservado
Dashboard oficial, Banco de Obras, Workspace, Identificação, Projeto da Obra, autenticação WordPress e dados existentes.

## Versão
Plugin atualizado para 1.0.6.
