# Hotfix 1.0.5 — Perfil na Sidebar

## Objetivo

Substituir o bloco informativo **Ambiente Editorial** pelo perfil real da conta WordPress, seguindo a referência visual aprovada do Verbum Studio.

## Implementado

- avatar com a inicial do usuário;
- e-mail da conta na base da sidebar;
- nome do usuário como informação secundária;
- ação **Sair** usando a URL segura de logout do WordPress;
- ação **Recolher** para compactar a sidebar em desktop;
- preferência de sidebar recolhida preservada no navegador;
- comportamento móvel preservado sem recolhimento forçado;
- novos assets versionados para evitar cache antigo;
- versão do plugin atualizada para `1.0.5`.

## Preservado

- rolagem interna da navegação;
- todos os grupos e menus da sidebar;
- Dashboard oficial;
- Banco de Obras;
- Workspace e workflow;
- Identificação e Projeto da Obra;
- autenticação WordPress.

## Resultado esperado

No rodapé da sidebar, o usuário passa a ver sua conta no lugar de **Ambiente Editorial**, com acesso direto a **Sair** e **Recolher**.
