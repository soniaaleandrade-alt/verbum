# Reteste HOM-009

Após instalar a versão 2.5.3, validar a Pesquisa do Capítulo no mesmo tamanho de janela usado na homologação.

O painel de progresso não pode cobrir filtros, categorias, botões, fontes ou ideias. Em larguras intermediárias, o painel deve ocupar uma área própria e deixar todos os controles clicáveis.
